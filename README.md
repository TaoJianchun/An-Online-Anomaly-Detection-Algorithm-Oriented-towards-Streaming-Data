# OODOFS: 面向流式数据的在线异常检测架构

这是一个专门用于在**开放特征空间**下进行持续网络流量异常检测的深度学习架构。本项目打破了传统静态深度学习模型必须依赖固定维度、无法应对动态网络对抗的底层限制，在网络入侵检测与流式数据异常监控中具备极高的工业实战落地潜力。

## 项目痛点与核心优势

在真实的流式网络环境中，黑客的攻击手法不断变异，未知的全新协议特征层出不穷。传统静态模型在面对这类流式高维流量时，极易陷入**灾难性遗忘**与**维度爆炸**的双重困境。

OODOFS 架构在**单次遍历（Single-Pass, Epoch=1）**的严苛约束下，成功实现了**“时空双维度”**的计算瓶颈突破：
* **时间维度（抗概念漂移）**：引入 **METER 动态自适应机制**，利用基于证据深度学习的智能演化控制器，实时量化流数据的不确定性，实现未知新型攻击的瞬时预警与免重训练的动态概念拟合。
* **空间维度（抗维度灾难）**：引入 **SAD 特征动态稀疏机制**，在全局损失函数中嵌入 $\ell_{1,2}$-混合范数正则化，在线对特征嵌入矩阵实施结构化物理剪枝，成功切除高维噪声。

---

## 系统核心架构架构

整个检测与自适应演化流程分为四个流式阶段：
1.  **流式拓扑建图**：利用滑动窗口模拟特征空间的开放式膨胀，基于特征-实例的非零响应坐标，构建高稀疏度的异构二分图，将样本与特征彻底解耦。
2.  **基准冷启动**：通过低维稠密潜空间投影与 GNN 邻居特征聚合，依托 **Deep SVDD** 确立高置信度的正常流量防御超网络质心 $c$ 与判定半径 $R$。
3.  **单次遍历在线检测**：针对突如其来的新特征触发动态扩容，在不破坏原有网络结构的前提下“热插拔”追加特征向量，计算实时欧氏距离进行极速预警。
4.  **误差回传与物理瘦身**：引入 $\ell_{1,2}$ 范数过滤器，将无贡献特征的权重在线收敛为零，并在不确定性突破 $3\sigma$ 统计阈值时瞬间生成参数偏移量。

## 实验表现与量化对比

本项目在包含多种隐蔽攻击（如 Backdoor 等变种）的真实网络流量数据集上进行了长周期的流式验证（特征暴露比例从 10% 递增至 100%）。

### 1. 消融实验结果 (Ablation Study)

| 模型变体 | 准确率 (Accuracy) | 精确率 (Precision) | 召回率 (Recall) | 综合 F1-Score | 核心结论 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **变体一 (Base GNN)** | 0.9501 | 0.8214 | 0.1533 | 0.2584 | 缺乏演化与降噪，性能快速僵化 |
| **变体二 (+SAD)** | 0.9520 | **0.9880** | 0.0821 | 0.1515 | 降噪极强，但无 METER 导致对新攻击失明 |
| **变体三 (+METER)** | 0.8805 | 0.3544 | **0.7215** | **0.4753** | 强于捕获新攻击，但误报极其泛滥 |
| **OODOFS (完整模型)** | **0.9829** | **0.9730** | **0.3091** | **0.4692** | **时空协同，完美化解“告警疲劳”** |

### 2. 基线算法横向对比 

与主流的代表性异常检测算法相比，在面对 196 维流式高维膨胀空间时，传统算法因无法克服深度噪声干扰导致精确率低下。本模型成功在单次遍历中**主动淘汰了 66.33% 的无效高维噪声**，表现出断层式的抗噪鲁棒性：

* **Isolation Forest**: Precision = 13.71% | F1 = 0.1337
* **One-Class SVM**: Precision = 10.99% | F1 = 0.1806
* **Local Outlier Factor**: Precision = 27.20% | F1 = 0.2693
* **OODOFS (本文模型)**: **Precision = 97.30%** | **F1 = 0.4692**

├── plot_results.py              # 实验运行监控与结果折线图/柱状图绘制脚本
